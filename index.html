Twin-in-the-Loop rApp on a Virtual RIC

Twin-gated RAN optimisation as an rApp on a standalone Virtual RIC: a Sionna RT digital twin scores every candidate change before it is recommended. Four functions — capacity (azimuth / tilt / power), slice PRB shares, energy, and an MCS / OLLA audit — each behind the twin gate.

Runner notebook (Colab)The rApp itself, standalone: change MODE, FUNCTION and COUNTER_SET at the top, Run all, and read the result in the last cell. The study network and the test counter sets are built in; it also runs locally in Jupyter, with no Google account. Run the rApp — consoleThe advanced path: choose a single tower or the cluster, see the existing radio configuration, ingest counters, select the function, and copy the run package into the notebook. No files, no downloads. SourceThe runner notebook, the console page, the engine modules (twin, guarded search, cluster, MCS audit, SYS environment, PPO policy) and the open city scene the twin traces.

Step 3 — Select the function, hand the run to the twin

The run package (what the button sends to the runner; copy it to run in the notebook instead)

How the run works, honestly. The optimisation itself — the ray-traced twin, the SYS link curve and slice environment, the guarded search, the audit's histogram fit — is the prototypes' own code: the button sends the run package to the local runner, which executes notebook/rapp_run.ipynb with it on this Mac (Sionna RT on the GPU, Sionna SYS) and returns what the twin verified. The page itself only prepares the run and draws the result. Nothing is emitted unless it passes the twin gate; a run that finds nothing worth changing says so and keeps the as-built configuration.
